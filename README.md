# TRAX - Fitness Management App

Fitness merkezi üye yönetim uygulaması.

## Kurulum

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Not

Bu React+TypeScript+Vite yapısı, basit HTML versiyonundan port edilmektedir.
Tüm component'ler `/src/app/components/` klasöründedir.
