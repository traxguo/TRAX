# Weekly Content Run

Produce one week of Instagram content (default: 3 feed posts; reels
scripts on request) in a single pass. English by default (US market).

1. **Angles** — trax-analyst: quick scan for 3-5 fresh angles/gaps
   (skip or shorten if the owner already gave a theme).
2. **Plan** — trax-strategist: pick 3 post concepts for the week,
   balanced across the brand pillars (Problem→Solution / Feature /
   Proof / Tip), each mapped to a funnel stage.
3. **Copy** — trax-copywriter: per post, 1 hook headline (fits the
   visual), caption + CTA ("14-day free trial — link in bio ↗"),
   4-6 niche hashtags.
4. **Visuals** — trax-designer: render each post as a 1080×1080 PNG
   (brand system: ink bg, one red moment, wordmark + @traxapp), view
   its own output before returning.
5. **Deliver** — send the PNGs to the owner with paste-ready captions
   and a suggested posting order/schedule. Ask for revisions in one
   batch rather than shipping unreviewed variations.

Run steps 3-4 in parallel per post where possible. Never invent
metrics or features; product facts live in the trax-brand skill.
